# 가벼운 엔진 — 걸린 시간 기록 + 폰 예상

측정 환경: 클라우드 컨테이너 CPU 4코어 (x86), RAM 16GB. "동시 작업" 표시가 있으면 다른 작업과 CPU 를 나눠 쓴 값이라 실제보다 느림.
폰 예상: 중급 안드로이드 CPU 를 이 환경의 1/2 ~ 1/6 속도로 가정 (추정 — 실측 전).

## 데이터 준비 (PC/서버에서 한 번 — 폰과 무관)
| 작업 | 측정 | 비고 |
|---|---|---|
| 데이터셋 조각 1개(1GB) 받기 | 17초 | |
| 조각 1개 처리 (4K 곡 약 90곡 추출: 디코딩 + 박 정렬 멜) | 115~132초 | 동시 작업 |
| 4K 곡 1,000곡 모으기 | 조각 약 11개 → 약 25분 | |
| 저장 용량 | 곡당 약 3.5MB → 1,000곡 약 3.5GB | |
